Medallion batch pipeline

How the data engineering project is deployed in ca-central-1, as provisioned by Terraform.

  1. 1Lambda writes customers, products, orders and order lines into MySQL every 5 minutes.
  2. 2DMS reads the MySQL binary log: a full load first, then every change.
  3. 3DMS writes each change as CSV, with an Op column, under bronze/ through the S3 gateway endpoint.
  4. 4Glue transform jobs read new bronze files (bookmarks) and write hashed Parquet under silver/.
  5. 5Glue load jobs copy silver into sales.stage_* tables in Redshift through a Glue connection.
  6. 6Stored procedures merge staging into SCD Type 2 dimensions: expire the old version, insert the new one.
  7. 7QuickSight reads the gold tables for the sales dashboard.
  8. ⏱EventBridge starts the Step Functions state machine every hour: dimensions load and merge in parallel, then facts.
