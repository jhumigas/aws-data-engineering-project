# Walkthrough 0: Prerequisites and Permissions

What you need before provisioning anything by hand in the AWS Management Console and CLI.

## Tools and Access
- **AWS Account** with administrative access.
- **AWS CLI** configured locally.
- **SQL Client** (e.g., DBeaver) for database interactions.

## User Permissions
Create an IAM user or role with administrative access to perform the subsequent provisioning steps.
