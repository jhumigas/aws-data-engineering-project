Proposed Test Sequence: Source to Bronze

A 4-step automated flow to verify data landing

Verification Flow
Step 1

Provision Infrastructure

Run terraform apply to create RDS, DMS, and S3.

▼
Step 2

Apply Migrations (Flyway)

Execute local DDL scripts to set up the dev schema and tables.

▼
Step 3

Start DMS Task

Activate the replication task to begin CDC monitoring.

▼
Step 4

Generate & Verify Data

Trigger Lambda generator and check s3://.../bronze/ for CSV files.
