Option A: Choosing a Migration Runner

Liquibase / Flyway implementation details

1. Local Runner

Pros

  • Easiest to debug
  • No extra AWS cost
  • Direct use of local .sql files

Cons

  • Requires local installation
  • Needs local network access to RDS
Workflow

terraform apply ➔ local-exec ➔ flyway migrate

2. Lambda Runner

Pros

  • True "Infrastructure as Code"
  • Works in CI/CD pipelines
  • Bypasses local network issues

Cons

  • Requires packaging a JAR/Binary
  • More IAM permissions needed
Workflow

terraform apply ➔ aws_lambda_invocation ➔ migrate
