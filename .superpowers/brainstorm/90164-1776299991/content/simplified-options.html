Simplified DDL Automation

Focusing on tools you already have: UV and Lambda

1. Lambda Init (Recommended)

Pros

  • Full "Hands-off" deployment
  • No local DB tools required
  • Verified within your VPC

Cons

  • Requires adding SQL logic to Lambda
Workflow

terraform apply ➔ lambda_invoke(init)

2. Local UV Script

Pros

  • Uses uv (already installed)
  • Direct control over DDL

Cons

  • Semi-manual
  • Requires local network access to RDS
Workflow

uv run scripts/setup_db.py

Decision Point

Which approach would you like to use to get the tables created in RDS?
