Approaches for DDL Automation

A

Liquibase / Flyway

Industry standard for DB migrations. Requires a runner (CLI, Docker, or Lambda).

B

Custom Lambda Init

Use the existing data-generator Lambda (or a small wrapper) to run the DDL on first start.

C

Terraform local-exec

Run mysql CLI directly from the machine running Terraform. Fastest but requires mysql client.
